# Capitol Crashers comics: scripts and Makko prompts

Generated from the issue files in `story/`. Edit those, not this.

## How to add art

1. Generate each panel in Makko with the style line below plus that panel's prompt.
2. Save it as `art/story/<panel id>.webp` (for example `art/story/p01.webp`).
3. In the issue file, set that panel's `art` to the file name (`art: "p01.webp"`).

Keep all lettering out of the art. Captions and speech bubbles are added by the page, so they stay editable and correctly spelled. Panels marked **stat** are drawn by the page and need no art.

**Style line for every panel:**

> Bold American comic-book illustration, heavy black ink outlines, halftone dot shading, rain-slick night lighting with neon magenta, cyan and gold accents, same painted-comic style as the Capitol Crashers fighter-select screen. No text, no lettering, no speech bubbles.
