## How to add art

1. Generate each panel in Makko with the style line below plus that panel's prompt.
2. Save it as `art/story/<panel id>.webp` (for example `art/story/p01.webp`).
3. In `story/panels.js`, set that panel's `art` to the file name (`art: "p01.webp"`).

Keep all lettering out of the art. Captions and speech bubbles are added by the page, so they stay editable and correctly spelled.

> Chibi comic illustration matching the Capitol Crashers comic: big heads, short bodies, clean black outlines, soft cel shading, rich painterly light. No text, no lettering, no speech bubbles, no signs with words.
